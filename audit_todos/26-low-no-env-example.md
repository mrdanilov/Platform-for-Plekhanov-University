# 26 · ⚪ Нет `.env.example`

**Severity:** Low — набор обязательных переменных собирается из prose в README
**Статус:** ⬜ не начато · **Оценка:** ~10 мин
**Зависит от:** `04` (чтобы пример не попал в git с реальными значениями)

## Где

Переменные объявлены в `config/settings.py` (строки 22, 27, 44, 49, 71), но нигде не
перечислены списком. Файл `.env.example` отсутствует. Требования к окружению разбросаны
по README (строки 262-272, 306-315).

## Что не так

Обязательные для продакшена переменные (`DJANGO_DEBUG`, `DJANGO_ALLOWED_HOSTS`,
`DJANGO_CSRF_TRUSTED_ORIGINS`, `DJANGO_SECRET_KEY`, `DJANGO_TRUST_XFF`) нигде не собраны
в одном месте. Новичок разворачивает проект по README, задаёт три переменные из раздела
«Проверки» и получает работающий, но незащищённый сайт (см. `08` — `check --deploy` с
дефолтами выдаёт 5 предупреждений). Отсутствие примера — одна из причин, почему
`SECURE_PROXY_SSL_HEADER` и `STATIC_ROOT` никто не добавил.

Дополнительно: `DJANGO_LOG_LEVEL` и будущие `DJANGO_HSTS_*` (задача `22`) добавят ещё
переменных.

## Направление фикса

1. Создать `.env.example` со всеми переменными, значениями по умолчанию и комментарием
   «для продакшена — обязательно задать».
2. Добавить `.env` в `.gitignore` (если используется python-dotenv) — **не добавлять**
   сам `.env` с реальными значениями. Текущий подход (`_secret_key()` пишет ключ в
   `.secret_key`) этого не требует, но `.env.example` всё равно полезен как документация.
3. Сослаться на `.env.example` из README и продублировать в нём таблицу переменных.
4. Проверить, что `python-dotenv` действительно нужен; если нет — оставить пример
   чисто документационным и не вводить новую зависимость.

## Критерии приёмки

- [ ] `.env.example` перечисляет все переменные, читаемые из `os.environ`
      (проверяется `grep -rn "environ" config/`).
- [ ] README отсылает к нему и содержит ту же таблицу.
- [ ] В репозитории нет файла с реальными секретами.
- [ ] `python manage.py check --deploy` на значениях из примера даёт ожидаемые
      предупреждения (то есть пример не «зелёный» по ошибке).


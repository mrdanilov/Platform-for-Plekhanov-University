# 06 · 🟠 Импорт только upsert: удалённые из файла занятия остаются навсегда

**Severity:** High — расписание расходится с источником без каких-либо признаков в UI
**Статус:** ⬜ не начато · **Оценка:** ~1-2 часа (режим + предпросмотр + тесты)
**Зависит от:** `01`, `02`, `09`, `10` · **Блокирует:** ничего

## Где

- `schedule/importer.py:249-363` — `import_schedule`: нет ни одного `delete()` по `Lesson`
- `schedule/excel.py:344-453` — `import_grid`: то же
- Противоречие в документации: `schedule/models.py:247` — «Импорт переписывает расписание
  всего университета»; README:242-243 — то же

## Что не так

Импорт только создаёт и обновляет. Занятия, которые диспетчер **удалил** из нового
файла, остаются в БД и продолжают показываться студентам. При этом UI и документация
обещают «переписывает расписание».

Два реальных сценария:
- **Точечный:** убрали пару из файла — students всё ещё её видят.
- **Катастрофический:** загрузили неполный файл (один факультет), рассчитывая на
  замену всего, — получили смесь старых и новых данных, и UI этого не показывает.

## Направление фикса

Выбрать одно из двух и **честно** отразить в документации. Сейчас несоответствие кода
и доки опаснее самого merge.

**Вариант A (рекомендую) — добавить явный режим «полная замена»:**
- флажок в `import.html`;
- в режиме проверки считать, что будет удалено, и показывать список удаляемых занятий
  (группа / день / пара / предмет) с количеством;
- удаление — только в слотах, которых нет в файле, и только в явно выбранном режиме;
- запись в `ImportLog` обязательно включая количество удалённых записей
  (сейчас модель имеет только `created/updated/skipped`, потребуется поле `deleted_count`).

**Вариант B — оставить merge, но переписать документацию:**
- в `models.py:247`, README и тексте `/import/` заменить «переписывает» на «дополняет/обновляет»;
- добавить в UI предупреждение: «занятия, отсутствующие в файле, сохраняются».

## Критерии приёмки

- [ ] Сценарий «убрали пару из файла» приводит к предсказуемому результату в обоих режимах.
- [ ] Режим полной замены показывает **список** того, что будет удалено, до записи.
- [ ] `ImportLog` содержит количество удалённых записей.
- [ ] Формулировки в README, `models.py` и UI соответствуют фактическому поведению.
- [ ] По умолчанию поведение не меняется (текущий merge сохранён), если выбран вариант A.

## Тест

```python
# 2) импорт файла с 1 занятием в режиме merge → в БД 2 (текущее поведение, зафиксировать)
# 3) импорт файла с 1 занятием в режиме полной замены → в БД 1

```

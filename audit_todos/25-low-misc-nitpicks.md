# 25 · ⚪ Мелочи: `i18n.format`, inline `onclick`, `random` в captcha и прочее

**Severity:** Low — гигиена кода, потенциальные 500 в будущем
**Статус:** ⬜ не начато · **Оценка:** ~30 мин суммарно
**Зависит от:** ничего

Набор независимых мелочей. Каждый пункт можно брать отдельно.

## 25.1 `i18n.translate` упадёт на строке с фигурными скобками

- **Где**: `schedule/i18n.py:171` — `return text.format(**kwargs) if kwargs else text`;
  аналогично `i18n.py:189` в `Trans.__getattr__`.
- **Проблема**: любая будущая строка в словарях `RU`/`UZ` с `{}` или `{0}` вызовет
  `KeyError`/`IndexError` → 500 на всей странице. Сейчас в словарях скобок нет,
  поэтому баг латентный.
- **Фикс**: `str.format_map` с пустым defaultdict, либо `string.Template`, либо
  валидация словарей тестом (запрет `{` в значениях без kwargs).
- **Тест**: тест, что все значения словарей совместимы с форматом.

## 25.2 `onclick` в шаблоне мешает введению CSP

- **Где**: `schedule/templates/schedule/_block.html:30` — `onclick="window.print()"`.
- **Фикс**: вынести обработчик в `{% block %}`-скрипт или в отдельный JS-файл, как уже
  сделано для темы в `base.html:60-85`.

## 25.3 `captcha` использует `random`, а не `secrets`

- **Где**: `schedule/captcha.py:80` (`rng = rng or random`), `:104`, `:131` (`random.choice`).
- **Оценка**: для визуального шума некритично, ответ всё равно сверяется на сервере.
- **Фикс**: `random.SystemRandom` (или `secrets` там, где нужно) — ноль усилий,
  убирает вопрос «предсказуем ли Mersenne Twister».

## 25.4 `set_language` меняет cookie по GET

- **Где**: `schedule/views.py:305` — состояние меняется GET-запросом.
- **Оценка**: меняется только cookie языка, CSRF-риска нет. Пометить комментарием,
  чтобы не выглядело как недосмотр.

## 25.5 Публичный CSV-дамп без ограничений

- **Где**: `schedule/views.py:699-706` — `export_csv_view` отдаёт всё расписание с ФИО
  преподавателей, без rate limit.
- **Оценка**: задокументировано как осознанное решение (README:302-304). Остаётся
  готовым датасетом для скрейпинга ФИО.
- **Фикс**: рассмотреть rate limit (одна строка через `throttle.py`) и/или пометку в
  README про предсказуемость данных.

## 25.6 Имена тестовых модулей разнородны

- **Где**: `schedule/tests.py` рядом с `test_*.py` (оба подхватываются).
- **Фикс**: переименовать `tests.py` → `test_substitutions.py` по содержимому.

## 25.7 Pillow не в `requirements.txt`

- **Где**: `tools/make_logo.py` требует Pillow, которого нет в зависимостях.
- **Оценка**: ожидаемо (разовый инструмент), но README:56 упоминает установку Pillow.
- **Фикс**: явно написать в README, что Pillow в зависимости приложения **не входит**.

## 25.8 `seed_menu_demo` в репозитории

- **Где**: `schedule/management/commands/seed_menu_demo.py`.
- **Оценка**: идемпотентна (`if Lesson.objects.exists(): return`), в проде не опасна.
- **Фикс**: пометить как dev-only в `help`.

## 25.9 `grid.build_grid` — `is_empty` вычисляется бессмысленно

- **Где**: `schedule/grid.py:169` — `'is_empty': not any(lesson.pk for lesson in lessons) if not lessons else False`.
  Выражение всегда даёт `False`, если список непустой, и `True` если пуст, то есть
  сводится к `not lessons`, но выглядит как содержательная проверка.
- **Фикс**: упростить до `not lessons` (или убрать, если поле не используется —
  проверить `grid['is_empty']` в шаблонах: используется в `views._empty_grid:196`).

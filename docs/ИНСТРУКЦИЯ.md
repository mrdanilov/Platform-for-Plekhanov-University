# Как пользоваться расписанием

Памятка по работе: как открыть расписание, где что искать, как добавить или
поправить занятие, как загрузить неделю из файла и как сделать копию базы.

## 1. Открыть расписание

### На своём компьютере

```powershell
cd C:\Users\Den\timetable
.venv\Scripts\python.exe manage.py runserver
```

Открыть <http://127.0.0.1:8000/>. Сайт работает, пока открыто окно с этой
командой; остановить — `Ctrl+C`.

То же самое одной кнопкой: двойной клик по `Platform.bat` в корне проекта →
пункт 1.

### Показать коллегам в локальной сети

```powershell
.venv\Scripts\python.exe tools\show_lan.py
```

Скрипт сам напечатает адрес вида `http://10.10.x.x:8000` — его и открывают
коллеги. Запускать с того компьютера, с которого показывают.

## 2. Что где на странице

- **«Расписание группы», «Преподавателя», «Кабинета», «Замены»** — четыре
  окна, открываются кнопками на главной странице.
- **«Сегодня»** (`/today/`) — расписание всего вуза за один день.
- **Стрелки рядом с неделей** — чётная и нечётная недели, переключаются без
  перезагрузки страницы.
- **Выгрузка и печать** — `/export/timetable.xlsx` и `/export/timetable.csv`.
  Тёмная тема переключается в шапке.

## 3. Добавить или поправить занятие

Адрес: <http://127.0.0.1:8000/admin/>. Вход — логин и пароль. Если их ещё
нет:

```powershell
.venv\Scripts\python.exe manage.py createsuperuser
```

**Админка открывается только с разрешённых адресов.** Пока список пуст —
только с того компьютера, где запущен сервер, для всех остальных страница
выглядит как отсутствующая. Чтобы открыть с рабочего компьютера, добавьте
его адрес в переменную `DJANGO_ADMIN_ALLOWED_IPS` (адреса через запятую,
можно сразу сеть вида `192.168.0.0/16`).

Разделы: Преподаватели, Учебные группы, Предметы, Аудитории, Типы занятий,
Время пар, Занятия, Замены, Обращения, Черновики правок, Журнал публикаций.

### Добавить занятие

1. «Занятия» → «Добавить».
2. Заполнить обязательно: группа, предмет, день, пара. Тип, преподаватель и
   аудитория — если известны, их можно добавить позже.
3. В поле «Недели» выбрать: каждую неделю, нечётные или чётные.
4. Сохранить.

### Поправить существующее

Быстрее прямо в списке «Занятий»: колонки «Преподаватель», «Тип» и
«Аудитория» правятся в таблице, без открытия записи. Кнопки со стрелками
сдвигают выбранное занятие на день вперёд или назад.

### Что система не даст удалить

Предмет и время пары, на которые ссылаются занятия, — сначала уберите сами
занятия, иначе расписание рассыпалось бы без предупреждения. Группа,
преподаватель, аудитория и тип удаляются свободно.

### Черновик и публикация

Правки собираются в «Черновиках правок» и на публичный сайт попадают только
после публикации — случайно испорченное расписание не выйдет наружу.
«Журнал публикаций» показывает, что было и что стало; там же можно вернуть
всё обратно.

## 4. Загрузить неделю из файла Excel

Сначала посмотреть, что будет загружено — ничего не записывается:

```powershell
.venv\Scripts\python.exe manage.py load_week_schedule "C:\Users\Den\Downloads\расписание_на_6_неделю.xlsx" --dry-run
```

Вывод показывает, сколько найдено занятий, групп, предметов, какая неделя
по чётности и что пропущено. Если всё верно — та же команда без `--dry-run`.

Флаг `--replace` очищает прежнее расписание и справочники перед загрузкой.
Без него новое расписание просто добавляется к старому.

**Перед любой загрузкой сделайте копию базы** (раздел ниже).

## 5. Копия базы

```powershell
.venv\Scripts\python.exe tools\backup_db.py
```

Копия ложится в папку `backups` рядом с проектом, проверяется сразу после
снятия и хранится 30 дней, последняя предыдущая остаётся всегда. Запускать
до загрузки недели и перед любыми правками «на живую».

## 6. Если что-то не так

| Симптом | Что делать |
|---|---|
| «Порт уже занят» | Сайт и так запущен — откройте <http://127.0.0.1:8000/> |
| Правка не видна на странице | Перезапустите сервер: при `DJANGO_DEBUG=0` шаблоны кэшируются до перезапуска |
| Админка не открывается с другого компьютера | Адрес компьютера не в списке разрешённых — см. раздел 3 |
| Страница без оформления | Соберите статику: `manage.py collectstatic --noinput` |
| Загрузка файла остановилась с ошибкой | Файл противоречит сам себе (например, разное название в шапке) — поправьте файл и запустите снова |

## 7. Проверки

Для тех, кто правит код:

```powershell
.venv\Scripts\python.exe manage.py test schedule
```

Ошибок быть не должно — тот же набор гоняется автоматически на каждом
отправлении в GitHub.
